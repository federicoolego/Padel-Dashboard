# Fede Pádel Stats

Dashboard estático con HTML, CSS, JavaScript y Chart.js.

## Ejecutar

```bash
python -m http.server 8080
```

Abrir `http://localhost:8080`. Para actualizar datos, reemplazar los dos JSON dentro de `data/`.

## GitHub Pages

Subir los archivos a la raíz del repositorio y habilitar **Settings > Pages > Deploy from a branch**.
